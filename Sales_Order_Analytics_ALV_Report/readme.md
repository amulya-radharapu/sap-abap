# Sales Order Analytics ALV Report

## Project Overview

An SAP ABAP program that retrieves and displays sales order header details using Classical ALV.

## Features

* Select sales orders using SELECT-OPTIONS.
* Retrieve sales order details from the VBAK table.
* Check whether records are available using IF condition.
* Prepare a field catalog to customize ALV columns.
* Display sales order details using REUSE_ALV_GRID_DISPLAY.
* Customize column headings, positions, and highlights.
* Enable editing for the creation date column.
* Set the customer number column as a hotspot.

## SAP Environment

* SAP ECC 6.0
* ABAP Workbench (SE38)

## SAP Tables

* VBAK — Sales Document Header Data

## ABAP Concepts

* TYPE-POOLS: SLIS
* TABLES

* Open SQL and SELECT
